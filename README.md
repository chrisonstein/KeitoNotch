# Keito Notch

Keito time tracking for macOS, living at the edge of your screen (notch, island or menu bar).

## Install

1. Download the latest **KeitoNotch-x.y.z.dmg** from [Releases](https://github.com/chrisonstein/KeitoNotch/releases/latest).
2. Open it and drag **Keito Notch** to **Applications**.
3. The first time: right-click the app → **Open** → **Open** (it isn't notarized by Apple).

After that, updates arrive by themselves (Settings → General → Updates), or via **Check for Updates…** in the menu-bar menu.

Requires macOS 14 or later.

## Windows

Keito Notch is also available for Windows 10 and 11 (source in [`windows/`](windows/)).

1. Download the latest **Keito.Notch_x.y.z_x64-setup.exe** from the [Windows releases](https://github.com/chrisonstein/KeitoNotch/releases?q=win-v) (tags starting with `win-v`).
2. Run it. No administrator rights are needed. The first time, Windows SmartScreen may warn because the installer isn't code-signed yet: choose **More info → Run anyway**.
3. Keito Notch opens its Settings: add your Keito Company ID and API key.

Open it with **Ctrl+Alt+T** or the tray icon. Updates arrive by themselves (Settings → General).
